## 它能帮你做什么？

很多人学英语听力时，总是「听懂了但说不出来」「模模糊糊却不知差哪里」。TypeCast 的方式很简单：**把真实播客里的一句话，反复听、反复打，直到你的耳朵真正锁住它**。

每一集都分为四个难度递进的练习轮次：

```
第一轮：看着字幕打 → 熟悉句子节奏
第二轮：字幕模糊打 → 强迫耳朵参与
第三轮：全程盲听打 → 真正靠耳朵辨识
第四轮：成绩回顾   → 看错误、看语速
```

打完一集，才算真的「听懂」了。

## 🎮 怎么使用？

1. 打开 **[typecast.51.edu.kg](https://typecast.51.edu.kg)**，无需注册
2. 从 375 集里挑一集，点击进入
3. 戴上耳机，跟着音频开始打字
4. 打错了不要怕，用 `Backspace` 退格；想重听这句，按 `Tab`
5. 需要暂停休息？点页面上的 **⏸️ 暂停** 按钮
6. 打完全部句子，查看这一集的成绩

完全免费，打开即用，进度自动保存在你的浏览器里。
