## 🎯 为什么叫「一举多得」？

很多人学英语常常陷入割裂：抱着单词书死记硬背、刷听力模模糊糊不知所云、开口说话吞吞吐吐。

**TypeCast 将学习过程立体整合，打一篇文章，多维同步提升：**

1. 👂 **真·磨耳朵（精听盲听）**  
   摆脱字幕依赖！通过声音直接刺激大脑，精准捕捉连读、弱读与辅音气流，直到耳朵形成生理级反射。
2. 🧠 **真实语境记单词（肌肉记忆）**  
   告别孤立背词！在点餐、警局、面试、音乐会等真实上下文里逐字母敲击，手眼脑耳协同，拼写与释义一次性牢固刻在指尖。
3. 🗣️ **地道生活场景口语（脱口而出）**  
   375 期纯正日常口语，涵盖餐厅点单、日常问候、就医问询、旅行入住。跟打一遍，就是对地道表达的一次肌肉预演，日常对话自然脱口而出。

## 🔄 四轮渐进式训练闭环

每一集都遵循科学的记忆强化阶梯：

```
第一轮：【看打（Show）】  完整显示文字，熟悉语速节奏与拼写
第二轮：【虚打（Blur）】  文字模糊提示，强迫耳朵抓取发音细节
第三轮：【盲打（Hidden）】纯耳辨识盲听，等宽槽位排版自然流畅
第四轮：【成绩复核】      实时 WPM、击键准确率与错词统计
```

- **⏸️ 随心暂停** — 临时离席一键暂停，杜绝听觉污染与计时失真
- **🔁 Tab 键快速重听** — 遇到生难句单键无限回听，直到彻底听清
- **💾 本地离线持久化** — 无需登录，学习记录自动安全保存在浏览器本地
