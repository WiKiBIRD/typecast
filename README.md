## 🎯 为什么叫「一举多得」？

很多人学英语常常陷入割裂：抱着单词书死记硬背、刷听力模模糊糊不知所云、开口说话吞吞吐吐。

**TypeCast 将学习过程立体整合，打一篇文章，多维同步提升：**

1. 👂 **真·磨耳朵（精听盲听）**  
   摆脱字幕依赖！通过声音直接刺激大脑，精准捕捉连读、弱读与辅音气流，直到耳朵形成生理级反射。
2. 🧠 **真实语境记单词（肌肉记忆）**  
   告别孤立背词！在点餐、警局、面试、音乐会等真实上下文里逐字母敲击，手眼脑耳协同，拼写与释义一次性牢固刻在指尖。
3. 🗣️ **地道生活场景口语（脱口而出）**  
   375 期纯正日常口语，涵盖餐厅点单、日常问候、就医问询、旅行入住。跟打一遍，就是对地道表达的一次肌肉预演，日常对话自然脱口而出。

## ⚔️ 四阶梯硬核闯关机制（通关解锁制）

TypeCast 拒绝“走过场式打卡”，引入了**严格的关卡解锁考核机制**。必须通过考核，才能解锁下一个生活场景，倒逼耳朵和双手形成真正扎实的肌肉记忆：

```
第一阶梯：【看打（Show）】    明文识音 · 熟悉发音节奏与拼写框架
第二阶梯：【虚打（Blur）】    模糊抓词 · 文本若隐若现，迫使耳朵抓取辅音细节
第三阶梯：【盲打（Hidden）】  单句盲听 · 纯听辨敲击，等宽槽位弹性排版
第四阶梯：【全文大挑战（Final）】硬核大考 · 综合考察 WPM 语速与击键准确率
```

> 🔒 **硬核考核规则**：
> 第四轮大挑战成绩必须 **≥ 80 分（合格）** 才能达成通关！系统才会为你解锁下一个全新生活场景。成绩未达标需原地复训，彻底杜绝“囫囵吞枣”，确保每一个场景真正学透吃透。

- **⏸️ 随心暂停** — 临时离席一键暂停音频与计时，防听觉污染与计时失真
- **🔁 Tab 键快速重听** — 遇到生难句单键无限回听，直到彻底听清
- **💾 进度自动保存** — 无需注册账号，学习进度与关卡解锁状态实时安全保存在用户的浏览器本地（IndexedDB），关掉网页下次打开依然继续！
